# Clash Tactician 2

بوت تيليجرام عربي ذكي للاعبي Clash of Clans: يقرأ بيانات اللاعب والقبيلة والحرب من
الواجهة الرسمية، يحوّل صورة قاعدة العدو إلى خطة هجوم مرسومة بالذكاء الاصطناعي، يتتبع
تطوّر حسابك، ويدير حرب قبيلتك من داخل تيليجرام.

## الميزات

- 🎯 **مخطط الهجوم:** صورة القاعدة + هدفك + تشكيلتك → خطة مراحل مرسومة بأسهم وأرقام،
  قابلة للتعديل («اجعل الدخول من الشمال») والحفظ في مكتبتك.
- 🧑 **ملف اللاعب وتطوره:** الإحصاءات والأبطال ومقارنة التطور مع الزمن.
- 🛡️ **لوحة القبيلة:** الأعضاء، التبرعات، مساهمات العاصمة، سجل الحرب وغارة العاصمة.
- ⚔️ **مركز الحرب:** النتيجة، حالة هجمات الأعضاء، وأهداف مقترحة لكل قتال.
- 🤖 **مساعد ذكي:** اسأل عن التشكيلات والاستراتيجيات بحرية.
- 🔔 **التذكيرات والمراقبة:** تذكير تلقائي بمن لم يهاجم في المجموعة، وإشعار عند بدء/انتهاء
  الحرب أو ترقية الأبطال.
- 🔑 **مفاتيح ذكاء اصطناعي شخصية:** NVIDIA NIM / OpenRouter / OpenAI / Gemini / خدمة متوافقة، مشفّرة.

## التشغيل محليًا

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env      # ثم عدّل القيم
python -m app
```

| `/start` | القائمة الرئيسية |

| `/profile` `/me` | ملفي وتطوري |
| `/link` `/unlink` | ربط/فك ربط حساب |

| `/members` `/top` | الأعضاء والتبرعات |

| `/watch` | مراقبة قبيلة |

## المعمارية

```
app/
  config.py          الإعدادات من متغيرات البيئة
  core/              الأخطاء، السجلات، التنسيق، الوقت
  storage/           قاعدة SQLite والمستودعات (+ ترحيل بيانات v1)
  coc/               عميل API والأخطاء والكتالوج والخدمات
  ai/                المزودون، خزنة المفاتيح، اختيار الإعدادات
  planner/           مخطط الخطة، البرومبت، الرسم، الخدمة
  bot/               الحالات، الأزرار، البطاقات، الوسائط، المعالجات
  services/          اللقطات، التذكيرات، المراقب الخلفي
  ops/               الصحة، التشخيص، IP الخروج، النسخ الاحتياطي
```
