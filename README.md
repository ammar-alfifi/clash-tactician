# Clash Tactician

بوت تيليجرام عربي لمساعدة لاعبي Clash of Clans. يشمل بيانات اللاعب والقبيلة وملخص قيادة الحرب من واجهة Supercell الرسمية، وتخطيط هجوم من صورة عبر OpenAI أو Gemini، ومفاتيح AI شخصية مشفرة.

## التشغيل محليًا

1. أنشئ رمزًا جديدًا للبوت عبر [@BotFather](https://t.me/BotFather). لا تستخدم الرمز الذي سبق نشره في المحادثة؛ أبطله أولًا.
2. ثبّت Python 3.11 أو أحدث، ثم أنشئ البيئة وثبّت الحزم:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e '.[dev]'
   ```

3. انسخ `.env.example` إلى `.env` وأضف الرمز الجديد محليًا:

   ```bash
   cp .env.example .env
   ```

4. شغّل البوت:

   ```bash
   python -m app
   ```

لتمكين بيانات اللعبة، أضف مفتاح المطور الرسمي في `COC_API_TOKEN`؛ قد يتطلب المفتاح عنوان IP ثابتًا مسجلًا في لوحة مطوري Supercell. يمكن ضبط `SUPPORT_CHAT_ID` لإشعار مجموعة المشرفين. لا تضع الأسرار في Git أو في مجموعة تيليجرام.

للتشغيل الدائم 24/7 بدون إبقاء جهازك مفتوحًا، راجع [DEPLOY_AR.md](DEPLOY_AR.md): نشر مجاني على Render (بدون بطاقة بنكية) مع منع النوم ونسخ احتياطي تلقائي لقاعدة البيانات.

لتذكيرات الحرب التلقائية، اضبط `WAR_REMINDER_INTERVAL_MINUTES` (بين 5 و1440، الافتراضي 60) ثم يفعّلها مشرف المجموعة بالأمر `/subscribe`. تفحص مهمة خلفية غرف الحرب كل دقيقة وترسل تذكيرًا واحدًا لكل فترة فقط عندما تكون الحرب جارية وهناك أعضاء لم يستخدموا كل هجماتهم.

لجعل مفتاح OpenRouter الخاص بمشغل البوت هو الافتراضي، أضفه في `OPENROUTER_API_KEY`. يستخدم البوت نموذجًا مجانيًا يدعم تحليل الصور مع تحويل تلقائي عند تعطله: `stealth/space-bunny-alpha` أولًا، ثم `google/gemma-4-31b-it:free` و`qwen/qwen3.8-27b:free` (قائمة الاحتياط لا تتجاوز 3 نماذج معًا). يمكن تخصيص النموذج الأول عبر `OPENROUTER_MODEL` والاحتياطيات عبر `OPENROUTER_FALLBACK_MODELS`، وتغيير عنوان الواجهة عبر `OPENROUTER_BASE_URL`. إذا لم يضبط المستخدم مفتاحًا شخصيًا فسيستخدم البوت هذا المفتاح المشترك؛ مفتاح المستخدم الشخصي يحل محله لحسابه فقط.

لتمكين حفظ مفاتيح المستخدمين الشخصية، ولّد مفتاح تشفير Fernet وضعه في `AI_KEY_ENCRYPTION_KEY`:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

لا تفقد مفتاح التشفير أو تغيّره دون ترحيل المفاتيح المشفرة الحالية. يضيف المستخدم مفتاحًا شخصيًا في الخاص عبر `/setkey openrouter` أو `/setkey openai` أو `/setkey gemini`؛ يختبره البوت قبل حفظ نسخة مشفرة. ويمكن إضافة أي خدمة متوافقة مع OpenAI عبر `/setkey custom` بإدخال عنوان API الأساسي ومعرّف النموذج والمفتاح. يحفظ البوت اتصالًا فعالًا واحدًا لكل مستخدم، ويحتفظ بعنوان الواجهة والنموذج مرتبطين بالمفتاح لتجنب خلط النماذج بين المزودين. `/testkey` يعيد الاختبار، و`/deletekey` يحذف الإعداد الشخصي ويعيد استخدام الافتراضي إن توفر. النموذج الشخصي الجاهز عبر OpenRouter هو `google/gemma-4-31b-it:free` مع النماذج الاحتياطية المجانية؛ و`gpt-4.1-mini` عبر OpenAI، و`gemini-2.5-flash` عبر Gemini. يبدأ المستخدم `/plan`، ثم يرسل هدفه وتشكيلته وصورة القاعدة. تُضغط الصورة وتزال بيانات EXIF وتُعالج مؤقتًا في الذاكرة، ثم تُرسل إلى المزود المختار. يحذف البوت رسالة الصورة من المحادثة إذا سمحت تيليجرام، والخطة المولدة اقتراح احتمالي يراجعه اللاعب. يمكن إنشاء مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/app/apikey)؛ توافر الحصة المجانية وحدودها يعتمد على المنطقة والحساب والنموذج وسياسات Google.

## الأوامر الحالية

- `/start` — القائمة الرئيسية.
- `/help` — شرح موجز للميزات.
- `/privacy` — معلومات التخزين والخصوصية.
- `/link #TAG` — ربط لاعب بملف تيليجرام (لا يثبت ملكية الحساب).
- `/player` — عرض بيانات اللاعب المرتبط؛ ويمكن تمرير وسم للاستعلام المباشر.
- `/clan` و`/war` — عرض القبيلة والحرب الحالية المرتبطة باللاعب، أو تمرير وسم قبيلة.
- `/members` — أعضاء القبيلة مع توزيع قاعات المدينة والأدوار.
- `/top` — لوحة الصدارة: الكؤوس والتبرعات ومساهمات العاصمة وأفضل المهاجمين.
- `/targets` — أهداف الهجوم المقترحة مرتبة بالنجوم وقاعة المدينة والهجمات المتبقية.
- `/warroom #TAG` — ربط مجموعة تيليجرام بقبيلة؛ للمشرفين فقط. زر «قيادة الحرب» يعرض الملخص للقراءة.
- `/subscribe [دقائق]` و`/unsubscribe` — تفعيل/إيقاف تذكير تلقائي بمن لم يهاجم في المجموعة المرتبطة (للمشرفين).
- `/remind` — إرسال تذكير هجمات فوري إلى المجموعة (للمشرفين).
- `/unlink` — إلغاء ربط اللاعب.
- `/setkey` أو `/setkey openrouter` — استخدام الافتراضي أو إعداد مفتاح OpenRouter شخصي.
- `/setkey openai` أو `/setkey gemini` — إعداد مفتاح مزود جاهز.
- `/setkey custom` — إعداد خدمة متوافقة مع OpenAI باستخدام عنوانها ونموذجها.
- `/testkey` و`/deletekey` — اختبار المفتاح الحالي أو حذفه.
- `/plan` — طلب خطة هجوم من صورة وبيانات الجيش بعد إعداد المفتاح.
- `/support` — فتح تذكرة مساعدة.
- `/idea` — إرسال اقتراح ميزة.
- `/cancel` — إلغاء إدخال التذكرة.

تتطلب أوامر بيانات اللعبة ضبط `COC_API_TOKEN`. الربط تنظيمي فقط؛ التحقق الرسمي من ملكية اللاعب لم يُنفذ بعد.

## ملاحظات أمنية

- يحتاج البوت إلى رمز تيليجرام جديد محفوظ في `.env` أو مدير أسرار.
- قاعدة البيانات المحلية تحفظ معرّف تيليجرام ووسم اللاعب المرتبط وطلبات الدعم ومفتاح مزود AI مشفرًا عند تفعيل الميزة. لا تخزن صور القواعد.
- استخدم مجموعة دعم خاصة، ولا تضف إليها أشخاصًا غير مخولين.
